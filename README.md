Hello hello hello  
This file contains the source code for the backend and frontend of my latest project.  
In this project, a website for discussing cinema has been designed.  

https://asgari.liara.run/  

Features  
✅ User registration and login with secure authentication  
✅ Sharing posts including image and movie description  
✅ Storing images in Cloudinary  
✅ Content management with user panel  
✅ Modern and responsive user interface  

🛠️ Technologies used  

**Backend**  
- Node.js & Express.js - server and API  
- MongoDB & Mongoose - database  
- JWT - authentication and session management  
- Cloudinary - storing and managing images  
- bcryptjs - hashing passwords  

**Frontend**  
- React.js - UI library  
- React Router - route management  
- Axios - API communication  
- Context API - state management  
- Tailwind - styling
